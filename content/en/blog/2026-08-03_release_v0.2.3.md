We released version `0.2.3` today – you can find it on the [GitHub release page](https://github.com/rosenpass/rosenpass/releases/tag/v0.2.3). 🎉

We have been working a lot on the first major release recently and we felt like we should backport some functionality and some fixes. We are starting our backports today with the `0.2.3` release and we are looking forward to backporting more during the upcoming months.

This backport release only contains some fixes / upgraded dependencies:

### Fixes
- upgrade all dependencies (except `liboqs`)
- upgrade build infrastructure (Nix, CI, formatters)
- add `CHANGELOG.md`

The average user will probably not notice any differences. 😉
